# Historical trial register (Stage 3, NS2)

_Generated by `audit/build_registry_historical.py` on 2026-10-20. Data: `registry_historical.csv`._

## Why a separate file

`registry.csv` / `REGISTRY.md` are the frozen Stage 1-2 register: 85 rows, **34 distinct
strategy/parameter trials**, and `bt_registry.trial_count()` (used by the frozen deflated-Sharpe
denominator, PLAN.md section 2) must keep returning 34. `REGISTRY.md` is re-rendered wholesale
from `registry.csv` by `bt_registry.render_registry`, so anything appended by hand there is lost
on the next build. The trials below are therefore kept in their own file and are **not** part of
the frozen `n_trials`; they feed only the version-2 scoring in `bt_stats_v2` / PLAN-stage3.md.

## What is registered here

Trials that were run in the two pre-programme studies but never written to `registry.csv`
(audit finding A8-02, AUDIT.md section 3.3):

| source | notebook | rows | signal-distinct | notes |
|---|---|---|---|---|
| SMA window x rebalance sweep | `sma/sma_trend_backtest.ipynb` | 65 | 65 | 13 windows (5..400) x 5 rebalance frequencies, 5 bp |
| SMA window x cost sweep | `sma/sma_trend_backtest.ipynb` | 39 | 0 | 13 windows x {0, 5, 20} bp, monthly; same signals as the grid |
| TimesFM rules | `timesfm/timesfm_forecast_backtest.ipynb` | 18 | 18 | R1, R4, R2 x 7 `P_STAR`, R3 x 9 `TAIL_Q10` |
| TimesFM comparisons | `timesfm/timesfm_forecast_backtest.ipynb` | 2 | 2 | ARIMA(1,1,1) under R1, trailing 1-month momentum |
| **total** | | **124** | **85** | |

Fuller trial count = 34 registered + 85 signal-distinct = **119** (158 if the cost-sweep rows are
counted as separate trials). These are the numbers used in AUDIT.md section 3.3 and in the
cross-trial deflated Sharpe of PLAN-stage3.md section 1.

## Columns

Same columns as `registry.csv` plus `source` (which sweep), `original_sample` (the sample the
trial was actually run on: SPY 1993+ or SPY 1997+) and `signal_distinct` (False for the cost
sweep). The `sharpe` column is filled only for the 26 SMA grid cells that the audit re-ran on the
long proxy (`audit/a8_sma_grid.csv`, format `dev / val`); all other rows carry
"not re-run on the long sample; counted for multiplicity only". `status` is `run` throughout -
none of these trials was evaluated under the frozen metric, so none is `pass`/`fail`.

## Assumptions recorded

- The SMA window list and the five rebalance frequencies are taken from `audit/a8_stats.py`
  constants (themselves read from the SMA notebook's parameter cell during the audit); the
  notebook cells were not re-executed for this register.
- TimesFM threshold grids are the `P_STAR` / `TAIL_Q10` lists in the TimesFM notebook (chosen
  values 0.55 and -0.08). ARIMA and momentum are counted once each.
- The 0 / 5 / 20 bp cost sweep is counted as not signal-distinct because the position series is
  identical to the monthly grid row; only the cost deduction differs.
